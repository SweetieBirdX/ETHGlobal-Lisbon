# Kinora

Autonomous music-licensing marketplace hero site — React + Vite + TypeScript + Tailwind CSS v4.

## Çalıştırmak için

Bilgisayarında [Node.js](https://nodejs.org) (18 veya üzeri) kurulu olması yeterli.

```bash
npm install
npm run dev
```

Terminalde çıkan `http://localhost:5173` adresini tarayıcıda aç.

> Not: Bu bir Vite + React projesi. `index.html` dosyasına doğrudan çift tıklayarak açmak çalışmaz — mutlaka `npm run dev` ile başlatılmalı.

## Prodüksiyon build'i almak için

```bash
npm run build
npm run preview
```
